# siftunit

Sift encode/decode helpers for unit payloads in pipelines.

**Site:** https://theworker02.github.io/siftunit/

## Install / run

```bash
git clone https://github.com/theworker02/siftunit.git
cd siftunit
node src/cli.js
node --test
```
